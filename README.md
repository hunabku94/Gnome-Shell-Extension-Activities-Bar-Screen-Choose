# Gnome-Shell-Extension-Activities-Bar-Screen-Choose
A GNOME add-on giving you control over which display shows the Activities bar, instead of limiting it to the default screen.

## Install (development)

```bash
make install
# log out / log in, then:
gnome-extensions enable activities-bar-screen-choose@hunabku94.github.io
gnome-extensions prefs activities-bar-screen-choose@hunabku94.github.io
```

Targets GNOME Shell versions 49-51. For notes and a test checklist, see [Doc/HANDOFF.md](Doc/HANDOFF.md).
