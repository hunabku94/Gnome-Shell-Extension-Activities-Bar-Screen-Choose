# Gnome-Shell-Extension-Activities-Bar-Screen-Choose
A GNOME extension that allows you to choose which screen displays the Activities bar, rather than restricting it to the default screen.

## Install (development)

```bash
make install
# log out / log in, then:
gnome-extensions enable activities-bar-screen-choose@hunabku94.github.io
gnome-extensions prefs activities-bar-screen-choose@hunabku94.github.io
```

Targets GNOME Shell 49-51. Notes and test checklist: [Doc/HANDOFF.md](Doc/HANDOFF.md).
